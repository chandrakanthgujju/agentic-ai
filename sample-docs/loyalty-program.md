# Acme Outfitters — Loyalty Program

_Fictional company used for the agentic-ai demo. Customer tiers match the mock database
(`get_customer_info`)._

| Tier | Lifetime spend | Benefits |
| --- | --- | --- |
| Bronze | $0 - $999 | 1 point per $1, birthday coupon |
| Silver | $1,000 - $3,999 | 2 points per $1, free return pickups, early sale access |
| Gold | $4,000+ | 3 points per $1, free express shipping, dedicated support line |

Points expire 12 months after they are earned. 100 points = $5 off. Tier status is reviewed on
1 April each year. Gold members also get a 45-day return window on non-electronics.
